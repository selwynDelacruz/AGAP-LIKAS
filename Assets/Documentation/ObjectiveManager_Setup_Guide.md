# ObjectiveManager Setup Guide

## Overview

The **ObjectiveManager** is a networked game ready system for AGAP-LIKAS that:
1. Shows a mission briefing panel when the game scene loads
2. Displays objectives customized by disaster type (Flood/Earthquake)
3. Waits for ALL players to click "Ready" before starting
4. Shows a countdown (3-2-1-GO!) when everyone is ready
5. Starts the game timer via GameManager

---

## Prerequisites

Before setting up ObjectiveManager, ensure you have:
- Unity Netcode for GameObjects package installed
- TextMeshPro package installed
- A working multiplayer lobby system (LobbyRoomManager)
- GameManager script in your game scene

---

## Step-by-Step Setup

### Step 1: Create the ObjectiveManager GameObject

1. Open your game scene (e.g., `TestKen`)
2. Create an empty GameObject:
   - Right-click in Hierarchy ? **Create Empty**
   - Name it `ObjectiveManager`

### Step 2: Add Required Components

Add the following components to the ObjectiveManager GameObject:

| Component | Purpose |
|-----------|---------|
| **ObjectiveManager** | The main script |
| **NetworkObject** | Required for multiplayer sync |
| **AudioSource** (Optional) | For countdown sounds |

### Step 3: Create the UI Panel

Create the objective panel UI structure:

```
Canvas
??? ObjectivePanel (Panel)
    ??? TitleText (TextMeshPro)
    ??? DescriptionText (TextMeshPro)
    ??? ObjectivesListText (TextMeshPro)
    ??? ReadyButton (Button)
    ?   ??? ReadyButtonText (TextMeshPro)
    ??? ReadyStatusText (TextMeshPro)
    ??? CountdownText (TextMeshPro)
```

#### UI Element Settings:

| Element | Recommended Settings |
|---------|---------------------|
| **ObjectivePanel** | Full screen overlay, semi-transparent dark background |
| **TitleText** | Font size: 48-72, Bold, Centered |
| **DescriptionText** | Font size: 24-32, Multiline, Left-aligned |
| **ObjectivesListText** | Font size: 20-28, Multiline, Left-aligned |
| **ReadyButton** | Prominent color (green), centered at bottom |
| **ReadyButtonText** | Font size: 24-32, "I'M READY" |
| **ReadyStatusText** | Font size: 18-24, shows "0/3 Players Ready" |
| **CountdownText** | Font size: 72-120, Bold, Centered, Initially hidden |

### Step 4: Assign References in Inspector

Select the ObjectiveManager GameObject and assign:

```
[Objective Panel UI]
??? Objective Panel ? ObjectivePanel (the main panel GameObject)
??? Title Text ? TitleText (TMP_Text)
??? Description Text ? DescriptionText (TMP_Text)
??? Objectives List Text ? ObjectivesListText (TMP_Text)
??? Ready Button ? ReadyButton (Button)
??? Ready Button Text ? ReadyButtonText (TMP_Text)
??? Ready Status Text ? ReadyStatusText (TMP_Text)
??? Countdown Text ? CountdownText (TMP_Text)

[Countdown Settings]
??? Countdown Seconds ? 3 (default)
??? Countdown Sound ? (optional AudioClip)
??? Game Start Sound ? (optional AudioClip)

[Debug]
??? Show Debug Logs ? ? (enable for testing)
```

### Step 5: Configure GameManager

The GameManager automatically detects ObjectiveManager. Verify these settings:

1. Select your **GameManager** GameObject
2. In the Inspector, find **Timer Settings**:
   - `Start On Awake` ? ? (checked)
   - `Wait For Objective Manager` ? ? (checked)

When `Wait For Objective Manager` is enabled and ObjectiveManager exists in the scene, the timer will NOT start automatically. Instead, it waits for ObjectiveManager to call `StartTimer()` after all players are ready.

### Step 6: Add to NetworkManager Prefab List

If using network prefabs:
1. Open your **NetworkManager** GameObject
2. Find **Network Prefabs** list
3. Add the ObjectiveManager prefab (if it's a prefab)

> **Note:** If ObjectiveManager is placed directly in the scene (not spawned), you don't need to add it to the prefab list, but it MUST have a NetworkObject component.

## Network Variables

| Variable | Type | Purpose |
|----------|------|---------|
| `readyPlayerCount` | `NetworkVariable<int>` | Tracks how many players clicked Ready |
| `totalPlayerCount` | `NetworkVariable<int>` | Total connected players |
| `hasGameStarted` | `NetworkVariable<bool>` | Prevents double-start, handles late joins |

## Customization

### Custom Objective Text

Modify the default text in the Inspector or edit `SetupObjectiveContent()` in the script:

```csharp
// In ObjectiveManager.cs - SetupObjectiveContent()
string customDescription = disasterType switch
{
    "Flood" => $"Your custom flood description...",
    "Earthquake" => $"Your custom earthquake description...",
    _ => $"Default description..."
};
```

### Custom Countdown Duration

In the Inspector, change **Countdown Seconds** (default: 3)

### Adding Custom Sounds

1. Import your audio clips into Unity
2. Assign them in the Inspector:
   - **Countdown Sound** - plays each second during countdown
   - **Game Start Sound** - plays when "GO!" appears

## Troubleshooting

### Issue: ObjectivePanel doesn't show
- Verify `objectivePanel` is assigned in Inspector
- Check that the panel's Canvas is set up correctly
- Ensure ObjectiveManager script is enabled

### Issue: Timer starts immediately (skips objectives)
- In GameManager, ensure `Wait For Objective Manager` is checked
- Verify ObjectiveManager exists in the scene BEFORE GameManager.Start() runs

### Issue: Ready button doesn't work
- Verify `readyButton` is assigned in Inspector
- Check Button component is enabled and interactable
- Look for errors in Console

### Issue: Players stuck waiting
- Check Console for network errors
- Verify all players have NetworkObject component
- Ensure server is properly tracking connected clients

### Issue: Late-joining player sees objectives when game already started
- This is handled automatically - `hasGameStarted` NetworkVariable syncs state
- Late joiner should skip to gameplay immediately

## Public API

### Methods

| Method | Description |
|--------|-------------|
| `AreAllPlayersReady()` | Returns true if all players clicked Ready |
| `HasGameStarted()` | Returns true if game has begun |
| `GetReadyPlayerCount()` | Returns number of ready players |
| `GetTotalPlayerCount()` | Returns total connected players |
| `ForceStartGame()` | (Server only) Skips waiting, starts countdown immediately |

### Example: Force Start for Testing

```csharp
// In a debug/test script
if (Input.GetKeyDown(KeyCode.F5) && GameManager.Instance.IsInstructor())
{
    ObjectiveManager.Instance?.ForceStartGame();
}
```

## Integration with Existing Systems

### GameManager Integration

ObjectiveManager automatically:
1. Detects GameManager via `GameManager.Instance`
2. Calls `GameManager.Instance.StartTimer()` when game begins
3. GameManager checks for ObjectiveManager and defers timer start

### PlayerPrefs Used

ObjectiveManager reads these PlayerPrefs (set by LobbyRoomManager):

| Key | Type | Usage |
|-----|------|-------|
| `DisasterType` | string | "Flood", "Earthquake", or "TestKen" |
| `TaskCount` | int | Number of victims to rescue |
| `GameDuration` | int | Game duration in seconds |
